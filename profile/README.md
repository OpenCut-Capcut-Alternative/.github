## Quick Start with OpenCut

This OpenCut tutorial is the short path most people need on the first day. Read it once beside the workspace, then repeat it on a small project before you bring in a long recording. Nothing here depends on a complicated account story. The goal is a sequence you can preview and export with confidence.

1. **Open OpenCut** - Confirm the preview area, the media area, and the OpenCut timeline are all visible. If the window feels tight, widen it before you add clips.
2. **Start a project** - Give the project a plain name and pick a folder you can find again. An OpenCut review is much easier when the project name matches the video you are making.
3. **Add media** - Bring in the picture and sound you are allowed to edit. Leave unrelated files out so the OpenCut timeline stays readable.
4. **Build the cut** - Place clips in order, trim the slow openings, and split where the thought changes. This is the heart of the OpenCut video editor.
5. **Layer sound and captions** - Put voice, music, and captions on separate tracks. Lower music under speech instead of replacing the voice track.
6. **Preview the whole piece** - Watch from the start once, then again around every cut. An OpenCut capcut alternative should still reward this slow check.
7. **Export a copy** - Write a new file when the OpenCut timeline looks right. Keep the project so a later OpenCut tutorial pass can revise the same cut.

Most people should leave unusual settings alone until a real project asks for them. The OpenCut timeline, a honest preview, and one saved project are enough to learn the rhythm.
